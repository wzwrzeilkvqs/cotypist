## 🤖 Overview

Cotypist runs a local language model and offers inline text completions in any app system-wide, giving you GitHub Copilot-style suggestions for emails, docs, and code.

Whether you're a newcomer or a veteran, Cotypist provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **System-Wide** | Inline suggestions work in any text field across your OS |
| **Local LLM** | Runs on-device models so completions stay completely private |
| **Tab to Accept** | Single keypress to accept or ignore each suggestion |
| **Custom Models** | Load any GGUF model to tune the suggestion style |
